Cara Hoskan di GitHub Pages

Langkah Percuma & Mudah Disebarkan Kepada Murid

1
Buat Repository Baharu:

Buka GitHub.com, buat repository baharu (contoh: pose-haiwan) dan setkan sebagai Public.

2
Muat Naik Fail index.html:

Muat naik fail index.html ini ke dalam cawangan main / master repository anda.

3
Aktifkan GitHub Pages:

Pergi ke Settings ➔ Pages, pilih Branch main dan tekan Save. Laman anda siap diterbitkan dalam masa 1 minit!

⚠️

Kamera Tidak Ditemui / Disekat

Sistem tidak dapat mengakses kamera telefon anda.

📱 Cara Penyelesaian Pada Telefon Pintar:
1
Buka di Pelayar Utama (Chrome / Safari):

Jika anda membuka dari WhatsApp / Telegram / Google Apps, tekan 3 titik di atas kanan dan pilih "Open in Chrome" atau "Open in Safari".

2
Benarkan Kebenaran Kamera (Permission):

Tekan ikon kunci 🔒 / tetapan di sebelah alamat laman web (URL bar) pelayar anda, kemudian hidupkan pilihan Camera ➔ Allow.
